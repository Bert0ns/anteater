# Archived Mascot Assets: Sweeping Plume Anteater

This directory contains the previous launcher icon and website assets depicting **The Sweeping Plume Giant Anteater** mascot, introduced in [#367](https://github.com/Bert0ns/cribrum/issues/367) and [#368](https://github.com/Bert0ns/cribrum/pull/368).

These assets were archived as part of [#432](https://github.com/Bert0ns/cribrum/issues/432) when Cribrum moved to the **6A-1** geometric monogram "C" anteater icon.

## Contents

- `android/drawable/`: Previous background XML (`#FBF8EF`).
- `android/mipmap-*/`: Previous foreground and monochrome adaptive icon WebP mipmaps (`mdpi` to `xxxhdpi`).
- `android/drawable-*/`: Previous notification icons (`ic_notification.webp`).
- `site/`: Previous website logo (`logo.png`) and favicon (`favicon.png`).
